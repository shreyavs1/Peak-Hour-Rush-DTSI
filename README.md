# Peak Hour Rush – Design Thinking for Social Innovation

## Project Overview
This project was developed as part of the **Design Thinking for Social Innovation (DTSI)** course at **KLE Technological University, Hubballi**.

The project focuses on solving **peak-hour congestion in BRTS bus stations** by studying commuter behavior, identifying pain points, and proposing practical solutions.

## Problem Statement
- Overcrowding during peak hours
- Long queues at ticket counters
- Wastage of paper tickets
- Poor maintenance
- Passenger safety concerns

## Design Thinking Process
- Empathy
- Define
- Ideate
- Prototype
- Testing

## Final Solution
- Additional ticket counters
- Tap-out system for card holders
- Improved passenger flow
- Better crowd management
